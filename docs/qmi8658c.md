# QMI8658C

## Overview

The QMI8658C is a complete 6D MEMS inertial measurement unit (IMU) with 9-axis sensor fusion and specified system-level orientation accuracy. It is manufactured by QST Corporation. It is designed for high-performance applications such as robotic vacuums, industrial tilt modules, pedestrian navigation, GNSS augmentation, 5G antenna stabilisation, inertial navigation, and large industrial UAVs. It features low power consumption, high stability, and high sensitivity, making it suitable for drones, robots, game controllers, and virtual reality devices.

## Specifications

The QMI8658C incorporates a 3-axis gyroscope and a 3-axis accelerometer in a small 2.5 × 3.0 × 0.86 mm 14-pin LGA package. It supports a UI interface compatible with MIPI I³C, I²C, and 3-wire or 4-wire SPI. Dynamic ranges span ±16°/s to ±2048°/s for the gyroscope and ±2 g to ±16 g for the accelerometer. A large 1536-byte FIFO can buffer sensor data to lower system power dissipation. The gyroscope noise density is 15 mdps/√Hz and accelerometer noise density is 200 µg/√Hz. When combined with the XKF3 9D sensor fusion algorithm, the system achieves ±3° pitch and roll orientation accuracy and ±5° yaw/heading typical specification. An internal 16-bit embedded temperature sensor is automatically enabled whenever the accelerometer or gyroscope is active, with a resolution of 1/256 °C per LSB and compensation optimal over −40 °C to +85 °C.

## Known Issues

Gyroscope noise at high ODR: Gyroscope noise increases significantly when the output data rate (ODR) is set above 1 kHz. It is not recommended to set the ODR beyond 1 kHz for applications sensitive to gyroscope noise.
AttitudeEngine (AE) complexity: Community reports indicate difficulty in successfully enabling and using the built-in AttitudeEngine internal fusion from the QMI8658.
Data clipping in AE mode: Gyroscope and accelerometer axis data can be clipped during the dQ (quaternion increment) calculation, and velocity increments can overflow, resulting in corrupted orientation output.
Gyroscope bias drift: The XKF3 sensor fusion algorithm includes in-run calibration to correct gyroscope bias drift over temperature and lifetime, but this requires proper configuration to be effective.

## Solutions

Keep the ODR at or below 1 kHz for noise-sensitive applications. Consult the datasheet's gyroscope noise density tables to select an appropriate ODR for your use case.
Monitor the AE clipping and overflow status flags in the AttitudeEngine output registers to detect when data integrity is compromised, and implement appropriate handling logic in firmware.
Use the XKF3 9D sensor fusion with in-run calibration enabled to automatically correct gyroscope bias drift over temperature and lifetime without requiring user intervention.
Offload orientation computation to the QMI8658C's on-chip AttitudeEngine to reduce interrupt rate to the host processor by up to 10×–100×, which also reduces power consumption in battery-driven devices.
For the CTRL9 command protocol, always read STATUSINT.bit7 (CmdDone) after issuing commands to confirm execution before proceeding.
