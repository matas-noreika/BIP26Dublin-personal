# Team 13 Day 1

Day 1 of the STMP has finished and I would like to share in summary what team
13 have been able to accomplish in just a few hours.

<!-- more -->

## git and github

The team and I found that using git and github can serve as a powerful
tool to enable all of us to collaborate together and have continuous logging
and tracking of progress as we work throughout the week. We found that although
git is mainly used with a terminal interface github provides an easy to use
application github desktop for people that are not so familiar.

## Project ideas

The team and I discussed two potential application ideas using the hardware
supplied.

The first idea we came up with was geofencing, geofencing is the technique of
using fixed point references and live sensor data to determine if the current
hardware lies inside or outside the bounds. This can be easily applied to a
robotics application like automated house cleaners or GNSS based lawn mowers.

The second idea is logging continuous position data to then generate a users
path similar to what apps like strava use to log jogging routes.

Each project would have their own level of complexities from limited memory
management, data transfer, data accuracy and robustness of application.

## Final Thoughts

I believe team 13 had a very productive day familiarising themselves with the
hardware and technologies.
